# ALXprodev-advanced_git

This repository demonstrates advanced Git usage and the GitFlow workflow.

## What is GitFlow?
GitFlow is a branching model for Git, designed to manage features, releases, and hotfixes in a structured way. It helps teams collaborate efficiently and maintain a clean project history.

## Branches
- `master`: Production-ready code
- `develop`: Main development branch
- `feature/*`: New features
- `release/*`: Release preparation
- `hotfix/*`: Quick fixes for production
